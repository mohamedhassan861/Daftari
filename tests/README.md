# الاختبارات · Checks

فحوص بتفتح البرنامج الحقيقي في متصفح من غير شاشة، بتاريخ ثابت، وتتأكد إن اللي المفروض يحصل بيحصل.

**قاعدة ثابتة: مفيش بيانات مستخدم حقيقية في الفولدر ده.** كل فحص شغال على بيانات مخترعة: يا الدفتر التجريبي اللي جوه البرنامج، يا بيانات مكتوبة في الفحص نفسه.

## التشغيل

```
pip install playwright && playwright install chromium
bash tests/run_all.sh
```

بيطبع كل فحص فشل، وفي الآخر الإجمالي. وبيشتغل لوحده على GitHub مع كل رفع (`.github/workflows/tests.yml`).

## إضافة فحص

ملف جديد اسمه `test_<الموضوع>.py`، يستخدم `lib.py` (فتح البرنامج، رقم سري جديد، بيانات تجريبية)، ويطبع `PASS`/`FAIL` عن طريق `ok(...)`. أي ميزة جديدة ليها فحص.

| الملف | بيتأكد من إيه |
|---|---|
| `test_bundle.py` | الملف المجمّع مطابق للمصدر، سياسة الصفحة، والمستخدم الجديد بيبدأ فاضي |
| `test_escape.py` | أي نص مكتوب عمره ما يتعرض كـ HTML |
| `test_day_change.py` | تغيّر اليوم والبرنامج مفتوح |
| `test_drive_keep.py` | قاعدة الاحتفاظ بنسخ Drive، وإن مفيش حاجة تتشال قبل الموافقة |
| `test_statement_match.py` | مطابقة كشف البنك والكارت (CSV و Excel) |
| `test_card_statement.py` | المطلوب سداده للكارت وحسبة الكشف |
| `test_pay_over.py` | سداد أكبر من الباقي |
| `test_new_category.py` | بند جديد من جوه الحركة |
| `test_plain_copies.py` | الحاجتين اللي مش متشفرين: قايمة التنبيهات وملخص الشهر |
| `test_excel_export.py` | تصدير Excel بالمكتبة اللي جوه البرنامج |
| `test_worker_push_hosts.py` | السيرفر بيكلّم خدمات التنبيهات المعروفة بس |
| `test_rate_lows.py` | جدول أقل سعر |
